# 🌟 About The Project

**Kirana AI** is a modern AI-powered kirana management application built using **Flutter** and **Supabase**.

This project focuses on creating a smart solution for local kirana stores with:
- 📦 Inventory Management
- 🤖 AI Based Features
- ☁️ Cloud Database Integration
- 📊 Sales Tracking
- ⚡ Fast & Responsive UI

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/garvitmalik-123/Kirana-ai.git
```

## Move into Folder

```bash
cd Kirana-ai
```

## Install Dependencies

```bash
flutter pub get
```

## Run Project

```bash
flutter run
```

---

# 🔐 Environment Variables

Create a `.env` file:

```env
SUPABASE_URL=your_url
SUPABASE_ANON_KEY=your_key
```
